# Worlds

*Disclaimer: Worlds is not a removed feature. Although the game mode “Worlds” is removed, the custom lobbies in Bloxd.io are (collectively) called “Worlds”.*

**Worlds** lobbies allow players to create their custom lobbies and games, whether they are public or private. There are also special variants of the Survival game mode named "Hardcore” and “Lifesteal” which can temporarily ban people, move max HP between people, or disable natural regeneration. In a Worlds lobby, the lobby can be in any of the Worlds game modes if you are the owner. It is recommended to open an Open World, as you can’t use most owner commands in other minigames even if you are the owner of the game. For a list of Worlds, click here.

You cannot place Protectors within a 192-block radius of true spawn (0, 0), and there is a 21X x 20000Y x 21z area around true spawn where you cannot break Blocks or use Moonstone Explosives, but you can place Water with Water Buckets.

# Setting up a World lobby
To create a World, click on the game mode you want to create a Worlds lobby for in the main menu of Bloxd.io, scroll down and click on the “+ Create” button.

## General options
### Name
Choose the name of your lobby. The name of all lobbies cannot be the same as any other world lobbies. **Important note: You cannot rename Worlds lobbies.**

### Visibility
Choose how private your lobby is:

 - **Public** — anyone can join your lobby, and your lobby is listed in the public list of Worlds lobbies in that game mode.
 - **Unlisted** — anyone can join your lobby, but it is not listed in the list of Worlds lobbies.
 - **Private** — only you can join the lobby, and it is not listed in the list of Worlds lobbies.
### Default gamemode
Sets the default game mode for everyone in your lobby. See the section “game modes in Worlds” below for more information.

## Visibility options (will only appear in the list of lobbies if your lobby is public)
### Description
Sets the description for your lobby. The description will be shown in the button to join your lobby in the list of Worlds lobbies.

### Colour
Sets the colour of the button to join your lobby in the list of Worlds lobbies.

### Emojis
Sets the emojis that will appear in the background of the button to join your lobby in the list of Worlds lobbies. You can add up to three emojis.

## Map options
### Map Type
Sets the type of world in your lobby:

 - **Default** — similar to the world in sandbox game modes, a nearly infinite number of biomes will be generated continuously across the world
 - **Flat** — the entire world is uniformly flat. The world is made up of grass blocks covering the surface, four layers of dirt beneath grass blocks, a layer of stone beneath the dirt and finally a layer of bedrock as the bottom of the world.
 - **One Block Wide** — similar to the removed game mode One Block Wide, biomes will still generate in this world, but the world is only one block wide.
 - **Sky Grid** — similar to the removed game mode Sky Grid, where the world is entirely made up of random blocks spaced 3 blocks apart from each other both vertically and horizontally.
## Advanced Options
### Disable protectors
Self-explanatory.

### Disable teleport requests
Choose whether players can teleport to each other.

### Disable tribe creations
Self-explanatory too.

### Void death height
Choose at which height would players die immediately. It has to be -100 or less. The default value of this option is -10000.

### Disable lobby spawn
Choose whether all players will spawn at a fixed place in the lobby and teleport to it.

### World border
Choose the radius from the lobby spawn that would be the “border” of the world, where players that crossed out of the border will be teleported back within the borders.

### Disable fall damage
Choose whether players can receive fall damage

### Disable mobs
Choose whether mobs can spawn in the lobby. If mobs are disabled, mob spawn orbs and mob spawners would also not work in the lobby.

### Set Warp
Sets a warp that all players can use at your current position with the name selected.

# Lobby moderation
## Setting game modes
### Default Gamemode
With this you can change the gamemode of all players in the lobby and the ones who are not in, the selects of gamemodes are: Survival, Creative, Peaceful, SurvivalAdventure, PeacefulAdventure, and Spectator.

### Select Player
Selects a specific player in the lobby.

### Update [Player's Name]'s Gamemode
Changes the game mode of the player you selected in the “select player” utility (see above).

## Kicking & Banning
### Kick Player
You must select a player and then press the kick button to kick them from the lobby. However, they are able to rejoin, so only use the kick function as a warning before banning the player.

### Kick All
Pressing this will kick everyone except yourself out of the lobby.

### Ban Player
When you ban a player, he or she is not able to join the lobby for an indefinite time.

### Unban Player
You can also choose to unban players, allowing them to join the lobby again.

# Game Modes in Worlds
*Not to be confused with Gamemodes. These are only available in Open Worlds.*

**Worlds Game Modes** are Game Modes that appear in **Worlds.** They are different from regular Game Modes because they are only in the Worlds Game Mode rather than the main screen. For example, you will never see Hardcore on the main page of Bloxd.io. The owner of the World can set the default game mode which everyone will be put into once they enter the World. The owner can also update each player's game mode separately. Note that you can only update a player's game mode if that player is in the lobby, so be careful as to who you allow to edit. They might come while you're away and grief your World.

## List of Worlds Game Modes
### Survival Game Modes
Survival:
Survival is the default Worlds Game Mode. In survival, you will have a health bar and can lose health.

This game mode's abbreviated name is "s" or "0".

### SurvivalAdventure
SurvivalAdventure is similar to Survival, but you cannot mine or place blocks. However, you can still interact with the following blocks and items:

 - Doors and trapdoors
 - Beds
 - Workbenches and Artisan Workbenches
 - Furnaces
 - Salvaging Tables
 - Enchanting Tables
 - Chests
 - Mobs and other players (by attacking or taming them)
 - Interactive boards (for example, “press to get” boards)
 - Code Blocks
 - Checkpoint Blocks (by saving your spawn point)
### Hardcore/Lifesteal
You can configure hardcore mode with /hardcore.

If you die in Hardcore, you don’t respawn, but if lifesteal is toggled, you do respawn with less max health. You get banned if your maximum HP is 0.

### Peaceful
Peaceful is substantially the same as Survival. However, you do not have a health bar (in other words, you have infinite health).

This game mode's abbreviated name is "p" or "2".

### PeacefulAdventure
PeacefulAdventure is the same as SurvivalAdventure. However, similarly to Peaceful, you do not have a health bar.

This game mode's abbreviated name is "pa" or "4".

### Creative
Creative is a game mode where players have an infinite supply of blocks and the ability to fly to build whatever they want.

This game mode's abbreviated name is "c" or "1".

### Spectator
Spectator is a game mode which is used to “spectate” events. You can fly, but cannot break, place or interact with most blocks. All players in Spectator are invisible in the third person camera and from other players.

This game mode's abbreviated name is "sp" or "5".

### None
Note: This game mode is removed.

The None Game Mode was a game mode that set your game mode to the default game mode. If you were in any other game mode and the default game mode changed, even if you were in that game mode, your game mode would not change. However, setting one's game mode to None after assigning them a specific mode would change their game mode when you changed the Default Mode.

# Worlds Browser
Upon selecting a Game Mode from the Main Menu, a scrollable list becomes available, allowing you to browse through both public and personal Worlds tailored to that specific Game Mode. For instance, to join a Custom One Block Lobby, click on its thumbnail, scroll down, and select "Explore". This will display a list of One Block lobbies with the highest concurrent player count.

## Old Worlds Browser
A Worlds browser previously existed, allowing players to browse a list of 30 Worlds lobbies, showcasing their names, descriptions, and types. The list was dynamically updated to prioritize Worlds with the highest player counts, displaying them at the top. Although the browser capped the displayed player count at 19, it was still possible to join lobbies with 20 or more players. During periods of low player activity, the browser would also display empty Worlds. To join a World, players could simply click on its name.

# Trivia
 - In older versions, you could place protectors around true spawn, meaning that servers with chunks around true spawn protected are very old.
 - The default gamemode used to be Peaceful before it was changed to Survival.
 - Chunks near spawn won't reset, unlike Survival, Peaceful, Creative and Factions.
 - You can only use the "Press to” Boards if you are the owner of the world.
 - In non-Open World gamemodes, don't have access to most of the owner commands.
 - You cannot create Bingo and Rocket Spleef as World lobby.
 - Players in adventure mode can no longer open Chests (not including Moonstone Chests)
 - If you are alone in a Worlds lobby, a text would appear at the bottom of the screen, saying "Play other Bloxd games for multiplayer!".
