# Future Ideas
This is an unordered list of ideas we would like to add to Bloxd Agent Blue. Contact us on Reddit or Bloxdhub if you would like to suggest anything.

 - **Schematic generation**: We plan to make the AI be able to generate schemtics for you. We plan to make it generate schematics in the official `.bloxdschem` file type, to avoid everyone the trouble of converting files to a specialized type.
 - **Live help**: We plan to let you play Bloxd.io directly, with the help of the AI assistant!
 - **Sources**: A list of sites that are communly used to train the AI (like [Bloxdhub](https://bloxdhub.com/), [BloxdForge](https://www.bloxdforge.com/), and the [Bloxd Wiki](https://bloxd-io.fandom.com/wiki/Bloxd.io_Wiki))
 - **Better Script editor**, including tooltips, better indentation, and braket highlighting.
 - **Agent commands**, like /se for bringing the chat into the script editor
